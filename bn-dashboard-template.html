Each configured BN/CN node appears once, regardless of partition membership. This is a logical node map, not physical rack topology. Unallocated CPUs are not guaranteed schedulable: memory, GPUs, state, reservations and policy also matter. GPU occupancy is not plotted.
CPU counts use Slurm CPU IDs; on nodes with one thread per core they also equal cores. Hover/click selection temporarily reveals all nodes so a job’s complete spread remains visible. The node and job queries are sequential; any differences are listed above.
